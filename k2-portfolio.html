The Core Contracts Suite

K2 Kinetic Router

Manages smart routing of assets, deposits of collateral assets, credit allocation checks, and triggers undercollateralized liquidations. Implements strict limit checks to enforce network safety.

K2 Incentives

Distributes protocol reward tokens dynamically based on total locked value (TVL), borrowing rates, and user participation indices. Aligns liquidity providers with network health.

K2 Treasury Vault

Acts as the secure vault for all protocol reserve assets. Protects funds through multi-sig governance structures, absolute vault isolation, and secure programmatic withdraw rules.

System Architecture

Ports & Adapters Model

Designed with strict domain isolation. The K2 Lending core logic has no direct coupling with specific blockchain state, enabling deterministic mathematical evaluation.

Pluggable Soroban and Stellar RPC adapters hook into standard ports, allowing seamless network transitions and local testing integration.

WASM Execution

Compiled to sandboxed WASM binaries ensuring minimal gas overhead and fast verification.

Zero Magic Constants

All pricing rates, caps, and safety limits are injected dynamically upon initialization.

Mathematical Bounds

Mathematical calculations use RAY-precision representation (18 decimals) to guarantee zero calculation drift.
