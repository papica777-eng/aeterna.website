# AETERNA-VHT • Настолен Болничен Клиент (Tauri Desktop Shell)
### Стандарт: IEC 62304 Class C • EU MDR 2017/745 Class IIb • GDPR Член 9 • Директива NIS2

Този модул представлява защитена, цифрово подписана настолна обвивка (Desktop Shell), написана на Rust и Tauri, която замества остарелите и опасни монолитни `.exe` файлове в болничните работни станции.

---

## 1. Защо Tauri Shell, а не обикновен .exe или Уеб Браузър?

| Показател | Стандартен .exe | Обикновен Браузър (Chrome/Edge) | AETERNA Tauri Shell |
|---|---|---|---|
| **Болнична Сигурност** | Висок риск (блокира се от Antivirus/EDR) | Няма апаратен контрол, риск от изтичане | Сертифициран системен контейнер с локален CSP |
| **USB/HID Баркод скенери** | Изисква тромави COM драйвери | Блокиран достъп до USB устройства | Директен hardware hook за 2D DataMatrix и NZIS кодове |
| **КЕП (Електронен подпис)** | Често несъвместим с 64-bit драйвери | Изисква уязвими разширения (extensions) | Директна интеграция през Windows CryptoAPI / PKCS#11 |
| **Потребление на памет** | 300 - 800 MB RAM | 800 - 1500 MB RAM | **< 45 MB RAM** (Бързо действие на стари болнични PC) |
| **Изолация на данните** | Неконтролиран диск достъп | Кешира некриптирани пациентски данни | Zero-Cloud LAN loopback (порт 8890), криптиран кеш |

## 2. Инструкции за Компилиране и Инсталиране

### Изисквания за болничния IT отдел:
* Rust Toolchain (`rustup default stable-x86_64-pc-windows-msvc`)
* Node.js (v18+) & Tauri CLI (`npm install -g @tauri-apps/cli`)
* Windows 10/11 Enterprise (LTSC съвместимост)

### Стъпки за компилация на инсталационен пакет (.msi / .exe):
```bash
cd hospital-tauri-client
npm install
npm run build
```

Компилираният инсталатор ще бъде генериран в:
`hospital-tauri-client/src-tauri/target/release/bundle/msi/AETERNA-VHT Clinical Portal_2.4.0_x64_en-US.msi`

## 3. Хардуерни Спецификации за Интеграция

1. **2D Лазерни Баркод Четци при Леглото:**
   * Honeywell Xenon 1900g / Zebra DS2208 (USB HID POS / Virtual COM).
   * Автоматично декодиране на GS1 DataMatrix (Банки за химиотерапия) и 12-цифрени баркодове от НЗИС направления.
2. **Смарт-карт четци за КЕП (Квалифициран електронен подпис):**
   * Поддръжка на картите на „Борика“ АД (B-Trust), „Инфонотари“, „Евротръст“ и „Спектър“ (StampIT).
   * Задължителен за финализиране и разписване на онкологични протоколи преди изпращане към НЗИС.
